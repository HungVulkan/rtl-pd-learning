
# RTL & Physical Design Learning Portfolio

A hands-on learning portfolio focused on digital design,
Verilog RTL, FPGA implementation, synthesis, STA, and
ASIC physical design.

## About

This repository documents my learning journey toward
a Physical Design Engineer internship.

The main focus is understanding the complete flow from
RTL design to physical implementation, while practicing
digital design on the Tang Primer 20K FPGA.

## Learning Roadmap

- [ ] Verilog fundamentals
- [ ] Combinational and sequential logic
- [ ] FSM design
- [ ] Testbench and RTL verification
- [ ] FPGA implementation
- [ ] Logic synthesis with Yosys
- [ ] Static Timing Analysis (STA)
- [ ] SDC timing constraints
- [ ] Floorplanning and placement
- [ ] Clock Tree Synthesis (CTS)
- [ ] Routing and PPA analysis
